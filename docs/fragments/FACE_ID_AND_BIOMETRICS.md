# Face ID and Biometrics

> **Superseded by `37_Authentication_and_Login.md` §3.** Retained verbatim as historical source material — no contradiction with `00_Master.md` was found.

iOS:
- Face ID.
- Touch ID where supported.

Android:
- Supported secure biometric authenticators.

Biometric templates never leave the device OS.
App stores only local enablement metadata and secure credential/token references.
