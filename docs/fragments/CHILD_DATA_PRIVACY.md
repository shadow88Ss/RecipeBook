# Child Data Privacy

> **Superseded by `33_Security_and_Privacy.md` §3.** Retained as historical source material only. Updated inline below to fold in the `00_Master.md` §10 pediatric-weight-management carve-out, so this no longer reads as excluding an explicitly enabled clinical workflow.

Parent-controlled access and minimal data collection remain the default posture for child profiles. This is not an absolute ceiling: when a parent/guardian explicitly enables a supported pediatric weight-management workflow (per `00_Master.md` §10.2), the platform may store the minimum longitudinal data that workflow requires — under the guardian's authorization (`GuardianAuthorization`, `29_Data_Model.md` §11) — while every such field still carries its own documented purpose, access rule, retention rule, and deletion/export behavior. Jurisdiction-aware child privacy controls apply throughout.
